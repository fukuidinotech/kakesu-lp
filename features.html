機能一覧

保存する 使い方を見る

共有シートから保存Safari などの共有ボタンから。押した瞬間に保存が終わります。
共有シートでタグとメモ保存したあと、その場で付けられます。押し間違いは「取り消す」で戻せます。
コピーしたURLを貼り付け一覧の右上のボタンから。
タイトルの後追い取得保存のあとで、ページのタイトルを取りに行きます。
サムネイルの後追い取得ページの画像（og:image）を取れたときだけ表示します。
本文の後追い取得検索で当てられるように、ページ本文の冒頭（最大4,000文字）も取り込みます。使い方
ファビコンの表示どのサイトのものか、一覧で見分けられます。
公開日の表示記事に公開日があれば出します。保存日では代用しません。
重複の判定追跡用パラメータや www. の違いを無視して、同じページと判断します。

掘り出す 使い方を見る

検索タイトル・URL・タグ・メモ・ページ本文をまとめて探します。
検索履歴確定した検索語を5件まで候補に出します。
タグで絞り込み一覧の上のタグを押すと、そのタグだけになります。
タブすべて / お気に入り / 未読。選んだ状態は次に開いても残ります。
未読の印開くと既読になります。編集画面で戻すこともできます。
お気に入り長押しメニューか、右スワイプで。
聞く貯めたものの傾向や使い方を、ことばで尋ねられます。続けて聞けば前のやり取りを踏まえて答えます。端末の中だけで動き、外へは送りません。使い方
記事を要約する長押しメニューの「要約する」から。そのページの本文だけを見て要約します。読むかどうかを決めるためのものです。使い方
記事について続けて聞く要約のあと、その記事について聞けます。答えの根拠はその記事の本文だけで、ほかに貯めたものは混ぜません。
記事の会話が残る記事ごとの会話は、新しいものから5件だけ端末に残ります。「聞く」の画面から開けます。iCloud には送りません。

整える 使い方を見る

タイトルの編集取得に失敗したときや、変なタイトルを掴んだときに直せます。
タグいくつでも。過去に使ったタグが候補に出ます。大文字と小文字は同じ扱いです。
タグの名前変更・削除設定の「ミュート」から、全項目のタグをまとめて付け替えられます。削除してもブックマークは消えません。使い方
メモなぜ保存したのかを書いておけます。検索の対象になります。
並べ替え指でドラッグ。全件を表示しているときだけできます。
取り直すタイトルを取れなかった項目を、もう一度取りに行かせます。
サムネイルの個別切替この項目だけ画像を消す、ということができます。
サムネイルの一括切替設定の「表示」から、一覧のサムネイルをまとめて消せます。

開く 使い方を見る

アプリ内で開くタップで開き、閉じると一覧の同じ場所に戻ります。
リーダーで開く広告や余計な表示を除いて本文だけを出します。既定はオンで、設定の「表示」から切れます。対応していないページはそのまま開きます。
ブラウザで開くログインや拡張機能が要るページは、長押しメニューから Safari へ。

消す・隠す 使い方を見る

削除の取り消し消した直後に「元に戻す」が数秒出ます。押さなければ、そこで初めて消えます。
文字列でミュートURL やタイトルに含まれる文字列を登録して隠します。
タグでミュートそのタグが付いた項目を隠します。
登録を残したままオフミュートは消さずに切れます。一時的に外したいときのために。
隠している件数の表示一覧の下に出ます。押すと設定が開きます。

持ち運ぶ・控える 使い方を見る

iCloud 同期同じ Apple アカウントの端末に出てきます。アカウント登録の操作はありません。使い方
週1の自動控え全件を JSON にして iCloud Drive の Kakesu フォルダに置きます。
書き出しいつでも JSON を書き出せます。送り先はご自身で選びます。
読み込みJSON から戻せます。すでにある URL は飛ばし、上書きしません。

のぞき見を防ぐ 使い方を見る

アプリのロック開くときに Face ID / Touch ID、または端末のパスコードで確認します。既定はオフです。
戻ったときの猶予リンクを開いて戻ってきただけでは聞きません。1分以上離れていたときだけ確認します。
App Switcher の覆いアプリを切り替える画面に、一覧の中身が写り込まないようにします。

ほかの場所から使う

未読のウィジェットホーム画面に未読の件数を出します。小さい方は1件、中くらいの方は3件まで、直近のタイトルも並びます。
ロック中のウィジェットアプリのロックをオンにしているあいだは、件数だけを出します。タイトルもサイト名も出しません。
ショートカット「ブックマークを保存」と「ブックマークを検索」を、ショートカットアプリや Siri から呼べます。
ショートカットとミュート検索は一覧と同じ結果を返します。ミュートして隠したものは返しません。

そのほか

ダークモードiOS の設定に従います。
文字サイズiOS の文字サイズ設定に追従します。
対応言語日本語・英語・ドイツ語・フランス語・スペイン語・韓国語・中国語（簡体字／繁体字）。
規約とポリシー設定の「このアプリについて」から、利用規約とプライバシーポリシーを開けます。
対応OSiOS 17.0 以降。「聞く」と「要約する」は Apple Intelligence に対応した端末（iOS 26 以降）でのみ使えます。

くわしい操作は使い方を、データの扱いはプライバシーポリシーをご覧ください。
