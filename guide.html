使い方

Kakesu

1. 保存する

入口は2つあります。どちらも押した瞬間に保存が終わります。

共有シートから

Safari などでページを開き、共有ボタン → Kakesu を選びます。 一覧に出てこないときは、共有シートの「その他」から Kakesu をオンにしてください。

コピーしたURLを貼り付け

URL をコピーした状態でアプリを開き、右上の貼り付けボタンを押します。

タイトルとサムネイルは、あとから埋まります。 保存した直後は URL だけが並びますが、アプリを開いているあいだに順次取りに行きます。 電波の悪い場所で保存しても、保存そのものは失敗しません。

同じページを二度保存しても、増えません （?utm_source= のような追跡用のパラメータや www. の違いは無視して、同じページと判断します）。

2. 見つける

  • 検索 — タイトル・URL・タグ・メモをまとめて探します。確定した検索語は5件まで候補に残ります。
  • タグで絞る — 一覧の上のタグを押すと、そのタグだけになります。もう一度押すと解除。
  • タブで分ける — すべて / お気に入り / 未読。選んだ状態は次に開いたときも残ります。

未読は丸い印、お気に入りは星で見分けます。

3. 開く

タップ

アプリの中で開きます。読み終えて閉じると、一覧の同じ場所に戻ります。開いた時点で既読になります。

長押し → ブラウザで開く

ログインが必要なページや、拡張機能を使いたいページはこちらから Safari に渡します。

4. 整える

長押し → 編集で、タイトル・タグ・メモ・未読を直せます。

  • タイトル — 取得に失敗したときや、変なタイトルを掴んだときはここで直します。
  • タグ — 入力して追加。過去に使ったタグは候補に出ます。大文字と小文字は同じものとして扱います。
  • メモ — なぜ保存したのかを一行書いておくと、あとで効きます。
  • サムネイル — この項目だけ画像を消す、ということもできます。

並べ替えは、長押し → 並べ替え → 指でドラッグ。 絞り込みや検索をしている最中は並べ替えできません（見えている一部だけ動かすと、全体の順番が壊れるためです）。

タイトルが取れなかった項目は、長押し → 取り直すでもう一度取りに行きます。

5. 消す・隠す

消す

左にスワイプ、または長押し → 削除。 消した直後に「元に戻す」が数秒だけ出ます。 押せば戻ります。押さなければ、そこで初めて消えます。

隠す（ミュート）

設定 → ミュート。URL やタイトルに含まれる文字列を登録すると、 それに当たるものが一覧から消えます。タグ単位で隠すこともできます。 どちらも登録は残したまま、オンとオフを切り替えられます。

隠している件数は一覧の下に出ます。押すとミュートの設定に飛べます。

6. 控えを取る

週に一度、保存した全件を JSON にして iCloud Drive の Kakesu フォルダに置きます。 「ファイル」アプリから開けますし、アプリを消したあとも残ります。

設定からは、いつでも書き出し（送り先はご自身で選びます）と、 読み込みができます。読み込みでは、すでにある URL は飛ばして、無いものだけ足します。 上書きはしません。

7. のぞき見を防ぐ

保存した URL は閲覧履歴そのものです。 端末を人に渡すことがあるなら、設定 → アプリのロックをオンにしてください。 アプリを開くときに Face ID / Touch ID、または端末のパスコードで確認します。

  • 既定はオフです。 必要な方だけ使ってください。
  • リンクを開いて戻っただけでは聞きません。 1分以上アプリを離れていたときだけ確認します。 読むたびに Face ID が出ると使えたものではないためです。
  • 顔や指紋が通らないときは、端末のパスコードでも開けます。 生体認証だけにすると、自分を締め出してしまうためです。
  • アプリを切り替える画面には、一覧の中身が写らないようにしています。

端末にパスコードを設定していない場合、この機能は使えません（設定の項目が押せなくなります）。

共有シートからの保存には、ロックは掛かりません。 保存の前に確認を挟むと、放り込んだつもりのものを取りこぼすためです。

8. 規約とポリシーを読む

設定の「このアプリについて」から、 利用規約とプライバシーポリシーを開けます。 同じ場所にアプリのバージョンも出るので、お問い合わせのときはこれをお知らせください。

別の端末で続きを読む

同じ Apple アカウントでサインインしていれば、そのまま出てきます。 アカウントを作る操作はありません。同期を止めたいときは、 iOS の「設定」→ Apple アカウント → iCloud から Kakesu をオフにしてください。

うまくいかないとき

  • 共有シートに出てこない — 共有シートの「その他」から Kakesu をオンにしてください。
  • タイトルが URL のまま — JavaScript で描画するページはタイトルを取れないことがあります。編集画面で直すか、取り直しを試してください。
  • 別の端末に出てこない — 設定の iCloud の状態を見てください。サインインしていない場合はそこに出ます。
