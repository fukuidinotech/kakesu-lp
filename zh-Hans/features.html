功能一览

保存 查看用法

从共享表单保存通过 Safari 等应用的共享按钮。按下的瞬间保存就完成了。
在共享表单里加标签和备注保存之后可以当场添加。按错了用“撤销”退回。
粘贴已复制的网址通过列表右上角的按钮。
稍后获取标题保存之后，再去取网页的标题。
稍后获取缩略图只有取得网页图片（og:image）时才显示。
稍后获取正文为了能被搜索命中，也会收录网页正文的开头（最多 4,000 字）。用法
显示网站图标在列表中一眼看出来自哪个网站。
显示发布日期文章带有发布日期时显示。不会拿保存日期顶替。
重复判定忽略追踪参数和 www. 的差异，视作同一个页面。

挖出来 查看用法

搜索标题、网址、标签、备注、网页正文一并查找。
搜索历史把确认过的搜索词保留 5 条作为候选。
按标签筛选点一下列表上方的标签，就只剩该标签的内容。
标签页全部 / 收藏 / 未读。选中的状态下次打开仍在。
未读标记打开即视为已读。也可以在编辑界面改回去。
收藏通过长按菜单，或向右轻扫。
提问可以用自己的话问收藏的倾向和用法。接着问会结合前面的对话来回答。只在设备内运行，不发送到外部。用法
为文章生成摘要在长按菜单选“摘要”。只读这一页的正文来生成。用来决定读不读。用法
就这篇文章继续提问看过摘要后，可以就这篇文章继续问。答案的依据只有这篇文章的正文，不混入其他收藏。
文章对话会保留每篇文章的对话只保留最新 5 条在设备上。可从“提问”界面打开。不会发送到 iCloud。

整理 查看用法

编辑标题获取失败，或抓到奇怪标题时可以修改。
标签想加多少都行。用过的标签会作为候选出现。大小写视作相同。
标签重命名与删除在设置的“屏蔽”里，可对全部项目统一更换标签。删除标签不会删除书签。用法
备注可以写下当初为什么保存。备注也在搜索范围内。
排序用手指拖动。只有显示全部时才能排序。
重新获取让应用再去取一次没能取到的标题。
单条切换缩略图可以只把这一条的图片关掉。
批量切换缩略图在设置的“显示”里，可以把列表中的缩略图一并关掉。

打开 查看用法

在应用内打开点一下打开，关闭后回到列表的同一位置。
以阅读器打开去掉广告和多余的东西，只显示正文。默认开启，可在设置的“显示”里关闭。不支持的页面照原样打开。
在浏览器中打开需要登录或扩展的页面，从长按菜单交给 Safari。

删除与隐藏 查看用法

撤销删除删除之后“撤销”会出现几秒。不去按它，那时才真的删掉。
按字符串屏蔽登记网址或标题中包含的字符串，把命中的内容藏起来。
按标签屏蔽把带该标签的项目藏起来。
保留规则只是关闭屏蔽规则不必删除，关掉即可。为了临时解除而设。
显示已隐藏数量出现在列表下方。点一下会打开设置。

带走与备份 查看用法

iCloud 同步会出现在使用同一 Apple 账户的设备上。没有注册账号这一步。用法
每周自动备份把全部内容写成 JSON，放进 iCloud 云盘的 Kakesu 文件夹。
导出随时可以导出 JSON。送到哪里由你自己决定。
导入可以从 JSON 恢复。已有的网址会跳过，不会覆盖。

防止被人看到 查看用法

应用锁打开时用 Face ID / Touch ID 或设备密码确认。默认关闭。
返回时的宽限只是打开链接再回来，不会追问。离开超过 1 分钟才确认。
应用切换界面遮挡切换应用的界面上不会映出列表内容。
锁定时不作答设备处于锁定状态时，快捷指令的“搜索”不会作答。小组件也只显示件数。
保护的范围保护的只是应用的界面。放在 iCloud Drive 里的 JSON 备份，可以直接在“文件”应用中读取。

从别处使用

未读小组件在主屏幕显示未读数量。小尺寸列出 1 条、中尺寸最多 3 条最近的标题。
锁定时的小组件开启应用锁期间只显示数量，不显示标题和网站名。
快捷指令“保存书签”和“搜索书签”可从快捷指令 App 或 Siri 调用。
快捷指令与屏蔽搜索返回的结果与列表一致。被屏蔽的内容不会返回。
锁定时的快捷指令设备处于锁定状态时，搜索不会作答。保存在锁定时依然可用（能随手丢进来才是它的意义）。

其他

深色模式跟随 iOS 的设置。
字号跟随 iOS 的字号设置。
支持语言日语、英语、德语、法语、西班牙语、韩语、中文（简体／繁体）。
条款与政策可从设置的“关于本应用”打开使用条款和隐私政策。
系统要求iOS 17.0 及以上。“提问”和“摘要”仅在支持 Apple Intelligence 的设备（iOS 26 及以上）可用。

详细操作请见使用方法，数据的处理请见隐私政策。
